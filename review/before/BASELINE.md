# Existing Fazhere Studio

Captured from https://fazhere.com/ on 20 November 2026 in Linux Chromium 156.0.8078.79. The desktop viewport measured 1440 × 900. The phone viewport measured 390 × 844 and used Chromium touch emulation. Both used DPR 1, a fresh browser context, default motion preferences and an unthrottled network. ANGLE used the SwiftShader software renderer.

The eight original JPEGs capture the experience a visitor received without changing its rendering setting. Entrance and reception rendered live on both viewports. Desktop switched to still mode while taking the project-room screenshot. The screenshot shows the live pause control and its post-capture telemetry records the change to stills. The phone project shot and both founder shots show the slow-renderer fallback. The adjacent device JSON files record the state immediately after each capture.
